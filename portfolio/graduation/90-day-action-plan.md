#### Part 3: The 90-Day Action Plan

##### The Framework
| Phase        | Weeks | Focus                       | Target                   |
| ------------ | ----- | --------------------------- | ------------------------ |
| **Launch**   | 1-2   | Polish, publish, apply      | First proposal sent      |
| **Land**     | 3-6   | Close first client, deliver | First \$2,000+ project   |
| **Scale**    | 7-10  | Retainer, team, systems     | First \$500/mo retainer  |
| **Optimize** | 11-12 | Raise rates, refine niche   | \$200/hr for new clients |

##### Week-by-Week Breakdown

##### Week 1: Polish
- [ ] Update Upwork profile with niche declaration
- [ ] Update LinkedIn headline and about section
- [ ] Publish Week 2 LinkedIn post (from content calendar)
- [ ] Send 3 warm lead outreach messages
- [ ] Apply to 1 Upwork job (practice)

##### Week 2: Publish
- [ ] Publish Week 3 LinkedIn post
- [ ] Comment on 5 posts/day in your niche
- [ ] Send 3 more warm lead messages
- [ ] Apply to 2 Upwork jobs
- [ ] Record 60-second profile video (optional)

##### Week 3: First Discovery Call
- [ ] Schedule first discovery call (warm or content lead)
- [ ] Use Day 14 script, take notes
- [ ] Send scope document within 24 hours
- [ ] Follow up in 3 days if no response
- [ ] Publish Week 4 LinkedIn post

##### Week 4: Close First Deal
- [ ] Negotiate scope and price (use Day 25 templates)
- [ ] Send invoice for 50% upfront
- [ ] Begin development (use Day 27 team if needed)
- [ ] Daily updates to client (use Day 26 template)
- [ ] Publish Week 5 LinkedIn post

##### Week 5-6: Deliver
- [ ] Complete core features
- [ ] Deploy to staging, client demo
- [ ] Fix feedback, deploy to production
- [ ] Send final invoice (50% on delivery)
- [ ] Ask for testimonial (use Day 24 script)

##### Week 7: Retainer Upsell
- [ ] 30-day check-in call (use Day 26 template)
- [ ] Present optimization opportunities
- [ ] Offer 500/month retainer
- [ ] Close retainer or schedule follow-up
- [ ] Publish case study on LinkedIn

#####Week 8: Team Test
- [ ] Post first contractor job (use Day 27 hiring process)
- [ ] Review 5 applicants, test 2, interview 1
- [ ] Assign first small task ($200-500)
- [ ] Review PR using Layer 4 checklist
- [ ] Publish Week 8 LinkedIn post

##### Week 9: Scale
- [ ] Hire first contractor (or decide to wait)
- [ ] Apply to 3 Upwork jobs with new portfolio
- [ ] Send 2 proposals using Day 25 templates
- [ ] Follow up on all pending proposals
- [ ] Publish Week 9 LinkedIn post

##### Week 10: Second Client
- [ ] Close second client (content or Upwork lead)
- [ ] Use team for development (if contractor hired)
- [ ] Deliver with Day 26 handoff checklist
- [ ] Plant retainer seed at delivery

##### Week 11: Rate Raise Prep
- [ ] Complete value review for first client
- [ ] Draft rate raise email (use Day 29 template)
- [ ] Send 30-day notice
- [ ] Prepare for negotiation

##### Week 12: New Rate, New Level
- [ ] First new client at $175-200/hr
- [ ] Existing client rate raises take effect
- [ ] Review 90-day results
- [ ] Plan next 90 days
